# Система взаимных проверок: загрузка работы, анонимные отзывы по шаблону, балл по рубрике, сроки.

## Назначение приложения

Приложение предназначено для взаимной проверки учебных работ студентами. Пользователь может загрузить свою работу, проверить работы других участников, оставить анонимный отзыв по заданному шаблону и выставить баллы по рубрике — набору критериев оценки.

Система позволяет отслеживать сроки сдачи работ и завершения проверок, а также просматривать полученные отзывы и оценки. В интерфейсе взаимной проверки вместо имён авторов и рецензентов отображаются условные идентификаторы.

## Основные пользовательские сценарии
### 1. Просмотр задания

Пользователь открывает раздел «Задания».
Просматривает карточки заданий, сроки сдачи и статусы своих работ.
Нажимает «Открыть задание» на выбранной карточке.
На экране «Задание и моя работа» знакомится с описанием, требованиями и критериями оценивания.

### 2. Сдача своей работы

Пользователь открывает нужное задание из раздела «Задания».
На экране «Задание и моя работа» выбирает файл.
Нажимает «Отправить работу».
После успешной отправки остаётся на текущем экране.
Интерфейс отображает сведения о прикреплённом файле и статус «Сдана».

### 3. Проверка чужой работы

Пользователь открывает раздел «Проверки».
Выбирает назначенную работу и нажимает «Проверить».
На экране «Проверка работы» знакомится с заданием и прикреплённой работой.
Заполняет поля отзыва по шаблону.
Выставляет баллы по каждому критерию.
Нажимает «Отправить отзыв».
После успешной отправки переходит в раздел «Мои проверки», где отображается выполненная проверка.
Имя автора проверяемой работы не показывается.

### 4. Просмотр своей выполненной проверки

Пользователь открывает раздел «Мои проверки».
Находит нужную проверку и нажимает «Посмотреть проверку».
На экране «Просмотр моей проверки» просматривает свой отзыв, выставленные баллы и дату отправки.
При необходимости возвращается к списку кнопкой «Назад к моим проверкам».

### 5. Просмотр полученных отзывов и оценок

Пользователь открывает раздел «Результаты моих работ».
Выбирает свою сданную работу и нажимает «Посмотреть результаты».
На экране «Результаты конкретной работы» просматривает отзывы, оценки по критериям и итоговые баллы каждой проверки.
Если отзывов ещё нет, видит сообщение об ожидании проверки.
Имена рецензентов не показываются: вместо них используются условные обозначения.

## Основные экраны

В приложении предусмотрено 8 экранов. В верхней навигационной панели на каждом экране доступны разделы «Задания», «Проверки», «Мои проверки» и «Результаты моих работ». При запуске приложения открывается экран «Задания».

### 1. Задания

Начальная страница со списком заданий, которые студент должен выполнить.

На экране отображаются:
название каждого задания;
срок сдачи;
статус своей работы: «Не сдана» или «Сдана»;
кнопка «Открыть задание».

При нажатии «Открыть задание» пользователь переходит на экран «Задание и моя работа» для выбранного задания.

### 2. Задание и моя работа

Страница с подробной информацией о выбранном задании и возможностью прикрепить свою работу.

На экране отображаются:
название и описание задания;
требования к выполнению;
срок сдачи;
раскрывающийся блок с критериями оценивания;
поле выбора файла;
кнопка «Отправить работу»;
сведения о сданной работе, если она уже отправлена.

После выбора файла и отправки пользователь остаётся на этой странице. Интерфейс показывает название файла и статус «Сдана».
Кнопка «Назад к заданиям» возвращает на экран «Задания».

### 3. Проверки

Страница со списком чужих работ, назначенных студенту для проверки. Здесь отображаются только незавершённые проверки.

Для каждой работы указаны:
условный номер без имени автора;
название задания;
срок отправки отзыва;
кнопка «Проверить».

При нажатии «Проверить» пользователь переходит на экран «Проверка работы» для выбранной работы.

### 4. Проверка работы

Страница для просмотра чужой работы, заполнения отзыва и выставления баллов.

На экране отображаются:
название задания и требования;
условный номер работы без имени автора;
прикреплённый файл;
поля отзыва: «Что получилось хорошо», «Замечания», «Рекомендации»;
критерии оценивания и поля ввода баллов;
итоговая сумма баллов;
кнопка «Отправить отзыв».

После успешной отправки отзыва пользователь переходит на экран «Мои проверки». Выполненная проверка появляется в истории и больше не отображается в разделе «Проверки».
Кнопка «Назад к проверкам» возвращает на экран «Проверки» без отправки отзыва.

### 5. Мои проверки

Страница с историей проверок, которые студент уже выполнил.

Для каждой проверки отображаются:
название задания;
условный номер проверенной работы;
дата отправки отзыва;
выставленный итоговый балл;
кнопка «Посмотреть проверку».

При нажатии «Посмотреть проверку» пользователь переходит на экран «Просмотр моей проверки».

### 6. Просмотр моей проверки

Страница с подробностями ранее отправленного отзыва.

На экране отображаются:
название задания и номер проверенной работы;
текст своего отзыва;
выставленные баллы по каждому критерию;
итоговый балл;
дата отправки.

Данные доступны только для просмотра. Редактирование отправленного отзыва в текущей версии не предусмотрено.
Кнопка «Назад к моим проверкам» возвращает на экран «Мои проверки».

### 7. Результаты моих работ

Страница со списком собственных сданных работ и информацией о полученных отзывах.

Для каждой работы отображаются:
название задания;
название сданного файла;
количество полученных отзывов;
кнопка «Посмотреть результаты».

Если отзывов ещё нет, отображается статус «Ожидает проверки».
При нажатии «Посмотреть результаты» пользователь переходит на экран «Результаты конкретной работы».

### 8. Результаты конкретной работы

Страница с отзывами и оценками, полученными за выбранную собственную работу.

На экране отображаются:
название задания;
сведения о сданном файле;
анонимные обозначения рецензентов;
текст каждого отзыва;
баллы по критериям;
итоговый балл каждой проверки.

Если работа ещё не получила отзывов, отображается соответствующее сообщение.
Кнопка «Назад к результатам» возвращает на экран «Результаты моих работ».

## Запуск frontend

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Откройте локальный адрес, указанный в терминале.

## Проверки

```bash
npm run build
npm run lint
```
